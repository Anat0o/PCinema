# Проверка PCinema 1.1 — 21 октября 2026

## Подтверждено

- Release-сборка и автономная публикация win-x64: без ошибок и предупреждений.
- 24 автоматических теста проходят. Покрыты разбор имён, неоднозначность, повторный импорт, отключённые и копируемые файлы, прогресс, 95%, перепривязка, TMDB offline/401/несколько совпадений/отсутствие изображений, DPAPI, встроенный и собственный токены, запрет скрытого fallback, сохранность истории и повторное открытие базы.
- Повторное сканирование без изменений не публикует обновление библиотеки (отдельный тест).
- Настоящий запрос configuration к TMDB с предоставленным токеном успешно авторизован. Значение токена в отчёт и журналы не включалось.
- Автономный artifacts/release-1.1/PCinema.exe успешно запущен на текущем компьютере. Для этого настройки защиты Windows не изменялись.
- Через настоящий интерфейс проверены главная, настройки, страница сериала, меню поверх видео, Escape назад, MP4 и MKV, пауза пробелом, F и выход из полного экрана. Полный экран перекрывает панель задач.
- После закрытия и перезапуска восстановлены серия E02 и сохранённая позиция; отметка завершённой E01 отображается в библиотеке.
- Исправлены обнаруженные во время проверки повторное присоединение элементов страницы сериала к WPF-дереву, наследование цвета текста поверх VideoView и шаблон выбранной аудиодорожки.
- Пользовательские экраны больше не создают отдельные окна. LibVLCSharp технически использует принадлежащую видеоповерхности прозрачную поверхность для наложения меню; она следует основному окну и не является отдельным экраном приложения.
- Установщик: artifacts/PCinema-Setup-1.1.0.exe; автономные файлы: artifacts/release-1.1. Видео и QA-база в поставку не входят.

## Оптимизации

- Строки каталога виртуализируются и переиспользуются; главный экран ограничивает число карточек.
- Поиск применяется после задержки 160 мс, без сетевых запросов.
- База читается и папки сканируются вне UI-потока; группы эпизодов собираются через lookup вместо повторного обхода всех эпизодов.
- SQLite индексирует series_id. Сканирование записывает только изменившуюся доступность файлов.
- Изображения декодируются с ограничением размера, кэшируются с освобождением неиспользуемых изображений; основные изображения предварительно загружаются в фоне.
- Переходы и наведения анимируют прозрачность и масштаб, а не геометрию интерфейса.
- Автосопоставление не запускается одновременно несколько раз; повторный неуспешный поиск ограничен 30 минутами в рамках сеанса; для 429 предусмотрены ограниченные повторы.

## Границы проверки

- Это проверка на текущем Windows-компьютере, а не на чистой виртуальной машине без SDK/VLC. Сборка опубликована self-contained и включает LibVLC.
- Не завершена отдельная матрица Windows DPI 100%, 150%, 200% и нескольких мониторов.
- Нет измерений FPS и задержек на большой реальной библиотеке или слабом ПК. Перечисленные оптимизации реализованы, но обещание конкретной частоты кадров не делается.
- Визуальная компоновка и элементы адаптированы по Cinejoy; пиксельная идентичность сайта не заявляется. Русские подписи, локальная библиотека и функции Windows создают намеренные отличия.
- В этой итерации принудительное завершение процесса и внешние SRT/ASS не проверялись вручную повторно. Механизм сохранения каждые 5 секунд сохранён; тесты хранилища проходят.
- Сертификат издателя отсутствует. В версии 1.0 наблюдалась блокировка Windows Application Control; в проверенной сборке 1.1 на текущем компьютере она не воспроизвелась.

## Обновление

Существующая база обновляется до схемы 2 добавлением таблиц метаданных и индекса. Идентификаторы серий, пути, отметки просмотра и позиции не меняются. Ранее сохранённый собственный токен имеет приоритет. При отсутствии своего токена по умолчанию используется встроенный.


## Обновление 1.1.1 — субтитры и логотип

- Общее отключение субтитров сохраняется сразу в SQLite и действует при следующем открытии плеера и смене серии. Автоматическое обновление списка дорожек не меняет предпочтение пользователя.
- Ручной выбор дорожки или успешное добавление внешних субтитров возвращает включённое состояние. Идентификаторы дорожек между разными файлами не переносятся.
- 25 автоматических тестов прошли. Новый тест проверяет сохранение отключения после повторного открытия базы и последующее включение.
- Нативный smoke-тест на MP4/MKV прошёл: выключенное состояние при двух последовательных открытиях MKV с субтитрами и ручное включение дорожки. Во время остановки dummy-видеовывода LibVLC печатает диагностические сообщения h264 get_buffer; проверки завершились с кодом 0.
- Добавлен оригинальный логотип P/play, PNG и ICO (16–256 px) для шапки приложения, окна, EXE и установщика. Воспроизводимый исходник: tools/Create-Icon.ps1.
- Публикация: artifacts/release-1.1.1; установщик: artifacts/PCinema-Setup-1.1.1.exe. Установка на чистой Windows повторно не проверялась.

## Обновление 1.1.2 — каталог и история серий

- События файловой системы запускают сверку после 2 секунд тишины; резервная фоновая сверка выполняется каждые 30 секунд, включая повторное подключение наблюдателей. Открытая библиотека и страница сериала обновляются после изменений.
- Подтверждённо удалённые файлы скрываются из каталога; сериал без оставшихся файлов также скрывается. Недоступный диск/UNC-корень сохраняет карточку и историю. Возврат файла по старому пути снимает отметку удаления.
- История вынесена в watch_history: TMDB ID сериала + сезон + номер серии. До распознавания используется локальный ID сериала; неоднозначные номера остаются раздельными. Дубликаты одного TMDB-сериала и серии объединяются для отображения.
- Миграция схемы 2 → 3 переносит существующий прогресс. При нескольких копиях используется более свежая запись; явный сброс позиции не заменяется старым прогрессом. Файловые записи сохраняются для восстановления истории и перепривязки.
- 33 теста проходят, включая автоматическое событие удаления без ручного сканирования, удаление целой папки, частичное удаление, возврат файла, отключение/подключение диска через подмену состояния, замену файла с тем же TMDB, независимость разных сериалов/сезонов/серий, явный перезапуск и миграцию старой базы.
- Проверка физического отключения USB, свежая установка на чистую Windows и повторный полный UI-прогон в этой итерации не проводились.
- Публикация: artifacts/release-1.1.2; установщик: artifacts/PCinema-Setup-1.1.2.exe. После миграции требуется версия 1.1.2 или новее; старые версии не поддерживают схему 3.

## Обновление 1.1.3 — 22 октября 2026

- Оформление субтитров в меню плеера: 4 размера, 4 шрифта, 3 цвета, обводка/контрастная обводка/тёмный фон, полужирный текст и предварительный просмотр. Сохранение в SQLite. Применение переоткрывает текущее видео с восстановлением позиции, паузы, громкости и выбранных дорожек. Стили ASS и графические субтитры могут игнорировать общие параметры; это указано в интерфейсе.
- Мышь: одиночный щелчок по свободной области видео — пауза; двойной — полный экран; колесо над видео — громкость. Интерактивные элементы и меню исключены из этих жестов. Для прозрачного WPF-слоя оставлена ненулевая альфа, чтобы Windows принимала щелчки и при скрытых кнопках.
- Автоплей по умолчанию включён: 5 секунд после завершения, кнопка отмены, проверка доступности следующего файла, отключение в настройках. Последняя серия не запускает цикл.
- Источники отображаются карточками с полным путём и доступностью, добавлением нескольких папок и общей пересканировкой. Удаление источника скрывает его файлы из каталога, не удаляя видео и историю. Повторное добавление возвращает записи. Вложенный отдельно подключённый источник остаётся виден при удалении родительского.
- 37 тестов прошли: сохранение/валидация оформления, отсчёт/отмена/отключение автоплея, удаление и возврат источников, пересекающиеся корни, ранее существующие тесты библиотеки и истории.
- Через настоящий UI проверены: пауза кликом по видео и кнопкой, перемотка мышью, полный экран двойным кликом, применение полужирного оформления с сохранением паузы и позиции, вид источников и переход S01E01 → S01E02 по завершении без нажатия «Далее».
- Выбор всех вариантов оформления и его фактический вид на всех форматах субтитров не проверялись; автоматизация теряла фокус при активации всплывающих ComboBox поверх VideoView. Установка на чистую Windows не проверялась повторно.
- Установщик: artifacts/PCinema-Setup-1.1.3.exe; автономная публикация: artifacts/release-1.1.3.

## Обновление 1.1.4 — 22 октября 2026

- Полноэкранный режим сохраняет прямоугольник окна и предыдущее состояние до изменения WindowChrome; при выходе восстанавливаются положение, размер и состояние.

- 37 автоматических тестов прошли; сборка и автономная публикация успешны. Проверены реальные строки серий, открытие меню, запуск из строки подготовленным движком, обычное разворачивание и полный экран. Перезагрузка Windows для измерения холодного старта и проверка нескольких мониторов не проводились.
