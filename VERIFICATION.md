# PCinema 1.0.0 — проверка текущей поставки

Дата: 29 октября 2026. Версия 1.0.0 — новая нумерация текущего приложения, без отката функциональности или изменения идентификаторов библиотеки.

## Проверено

- Release-сборка и 91 автоматический тест: разбор файлов, каталог, история, модульные пакеты и синхронизация на тестовых данных.
- WPF-компоновка 11 экранов при размерах 850×600, 1280×860 и 2560×1600, рендеринг при 100/150/200% (99 снимков в `artifacts/verification-1.0`).
- Фон главной — отдельный Canvas за содержимым. Изображение масштабируется по ширине с сохранением пропорций, нижние 45% плавно исчезают. Размер изображения не сдвигает карточки. Проверены декодированные растры 1600×900 и 900×1600; автоматическая проверка пропорций и высоты баннера.
- Карточка продолжения имеет фиксированную ширину 300 DIP и горизонтальное превью 300×169; справа на странице тайтла осталась только текстовая статистика.
- Компактная навигация: главная через логотип, библиотека и история значками справа; открытие рабочих страниц модулей через настройки.
- Нижняя панель плеера: градиент с непрозрачностью 44–69%, меню — 77%. Текст и значки не получают общую прозрачность. Размытие видео не используется.
- Установщик сохраняет прежний AppId и каталог. В поставке есть .NET и LibVLC; пользовательские базы в пакет не включаются.

## Ограничения

Рендеринг при разных DPI не заменяет перенос живого окна между мониторами. В этом выпуске не повторялись полный прогон реальных видео, визуальная проверка прозрачности поверх светлых сцен, PiP, трей и установка на чистую Windows. Реальный вход Google и синхронизация между двумя профилями не подтверждены: функция остаётся экспериментальной. Скорость холодного запуска после перезагрузки не измерялась.

## Воспроизведение проверок

```powershell
dotnet test PCinema.Tests/PCinema.Tests.csproj -c Release
dotnet run --project tools/DesignProbe -- artifacts/verification-1.0
dotnet run --project PCinema.Smoke -c Release -- 'path\episode.mp4' 'path\episode.mkv'
```

DesignProbe использует отдельный профиль, синтетические записи, изображения и файлы-заглушки, не видео пользователя. Для ручных тестов задавайте `PCINEMA_DATA_DIR` в отдельный каталог.
