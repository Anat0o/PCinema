## Возможности

- Локальная библиотека сериалов: сканирование папок, поиск и фильтры. Исходные видео не перемещаются и не переименовываются.
- Постеры, фон, описания сериалов и серий через TMDB; ручное распознавание и проверка комплектности сезонов.
- Встроенный LibVLC: MKV/MP4 и другие форматы, аудиодорожки, SRT/ASS, настройка цвета и размера субтитров, сохранение их отключения.
- История каждой серии с точной позицией, продолжение просмотра, автоплей. История сохраняется и без локальных файлов.
- Полный экран, картинка в картинке, сворачивание в трей и защита от повторного запуска.
- Компактная навигация: логотип открывает главную, справа — поиск, библиотека, история, настройки и аккаунт.
- Кинематографичный фон с плавным затемнением; прозрачные панели плеера. Локальная библиотека работает без интернета.
- Платформа модулей: рескины, темы, шрифты, дополнительные страницы и фоновые функции. Управление и открытие страниц модулей — в **Настройки → Модули**.

## Установка и обновление

Скачайте `PCinema-Setup-1.0.0.exe` со [страницы последнего релиза](https://github.com/Anat0o/PCinema/releases/latest). Установка для текущего пользователя, .NET и LibVLC включены; отдельно устанавливать VLC не требуется.

**1.0.0 — новая точка отсчёта нумерации текущего приложения.** Это не возврат к старому коду: сохранены нынешние функции и исправления. Установщик использует прежний AppId и каталог, библиотека и история не сбрасываются. Перед обновлением завершите PCinema через меню трея → Закрыть.

Добавьте папку в **Настройки → Библиотека**. Для получения метаданных подключите TMDB. Пробел ставит видео на паузу, стрелки перематывают, F переключает полный экран, P — PiP, Escape возвращает назад. Двойной щелчок по видео переключает полный экран.

## Модули и SDK

В релизе доступны три `.pcmodule`: **Compact**, **PT Sans** и **Таймер сна**. Устанавливайте их через настройки модулей. Программные модули выполняются с правами приложения; темы и шрифты не содержат исполняемого кода. Для программных модулей требуется перезапуск. `--safe-mode` запускает встроенное оформление без сторонних модулей.

[Документация SDK](docs/MODULES.md) · [Шаблон](templates/Module) · [Примеры](examples). Версия SDK **1.1.0** независима от версии приложения; совместимость API 1 сохранена.

## Google-аккаунт

Раздел **Настройки → Аккаунт и синхронизация** содержит интеграцию Google Drive для истории и переносимых предпочтений. Она **экспериментальная**: реальный вход и обмен между двумя профилями пока не подтверждены. Для работы локальной библиотеки вход не требуется.

[Настройка OAuth-клиента владельцем приложения](docs/GOOGLE-SETUP.md) · [Состав данных и протокол](docs/SYNC.md). Видео, пути источников, токены и пакеты модулей не входят в облачные снимки.

## Данные и приватность

Данные приложения находятся в `%LocalAppData%\PCinema`. Пользовательские токены защищаются Windows DPAPI. Удаление источника не удаляет видео или историю; файлы можно перепривязать через меню серии. Пользовательские данные сохраняются после удаления приложения.

Секреты, базы, видео и сборки исключены из Git. Издательская конфигурация TMDB/OAuth может подключаться из игнорируемого каталога `.secrets`; публичные исходники не содержат этих значений. Для собственной сборки доступны пользовательский токен TMDB и настройка Desktop OAuth-клиента.

## Сборка

Нужны Windows, .NET 10 SDK и Inno Setup 6.7+ для установщика.

```powershell
git clone https://github.com/Anat0o/PCinema.git
cd PCinema
dotnet test PCinema.Tests/PCinema.Tests.csproj -c Release
dotnet run --project PCinema/PCinema.csproj -c Release
./build.ps1 -Dotnet dotnet -Iscc 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe'
```

Сборка создаёт `artifacts/publish`, `artifacts/PCinema-Setup-1.0.0.exe`, SDK и пакеты примеров. Пользовательские библиотеки в поставку не включаются.

## Проверки

[Результаты и ограничения](VERIFICATION.md). Для изолированного профиля используйте `PCINEMA_DATA_DIR`. `tools/DesignProbe` проверяет компоновку, пропорции фона и размеры окна. Настоящее воспроизведение можно проверить через `PCinema.Smoke` на собственных MP4/MKV.
