## Возможности

- **Локальная коллекция:** добавьте папки с сериалами; PCinema найдёт видео во вложенных каталогах, не перемещая и не переименовывая файлы.
- **Постеры и описания:** поиск в TMDB, русские метаданные с английским запасным вариантом, ручное сопоставление и собственные постеры.
- **Продолжение просмотра:** отдельная история каждой серии, сохранение позиции каждые 5 секунд, при паузе и выходе. У распознанных серий история связана с TMDB, сезоном и номером, а не только с файлом.
- **Встроенный плеер:** LibVLC, звуковые дорожки, встроенные и внешние субтитры SRT/ASS, оформление субтитров и запоминание их отключения.
- **Автоплей:** следующая серия после пятисекундного отсчёта с возможностью отмены; отключается в настройках.
- **Удобная навигация:** тёмный интерфейс на русском, поиск, фильтры и действия рядом с каждой серией. Библиотека, настройки и плеер находятся в одном окне.
- **Обновление каталога:** обработка изменённых путей, проверка источников каждые 30 секунд и полная сверка каждые 10 минут. Удалённые файлы скрываются, а отключённые диски сохраняют библиотеку и историю.
- **Работа без сети:** локальное видео, история и ранее загруженные метаданные доступны офлайн. Аккаунт PCinema не нужен.

## Что нового в 1.2.0

- Вкладка **История**: все начатые и просмотренные серии, поиск и переход к странице сериала даже после удаления файлов. Сезон и серия видны, точная позиция хранится для продолжения без вывода времени в истории.
- **Проверить наличие всех серий** на странице тайтла: сравнение с сезонами и сериями TMDB, список недостающих файлов. Будущие серии и неизвестные даты показаны отдельно; спецвыпуски включаются флажком. Последний полный список сохраняется для офлайн-проверки с указанием даты.
- Один готовый движок на приложение, подготовленный кэш плагинов VLC в установщике, последовательная фоновая очередь команд.
- Одна перемотка при отпускании ползунка, объединение быстрых стрелок, мгновенная пауза по клику. Двойной щелчок переключает полный экран и сохраняет исходную паузу.
- Выбор **Автоматически / Программное** в настройках декодирования плеера; сохраняются позиция и дорожки.
- Фоновая запись истории с ожиданием при закрытии, асинхронные изображения с кэшем до 128 МиБ и обновление карточек без полного перестроения.

Локальная диагностика: `%LocalAppData%\PCinema\diagnostics`, три файла примерно по 2 МиБ; без названий, полных путей и токенов, без отправки данных. Замеры и ограничения: [VERIFICATION.md](VERIFICATION.md).

## Начало работы

Целевая платформа — **Windows 11 x64**. Текущая версия — **1.2.0**.

**[Скачать актуальную версию →](https://github.com/Anat0o/PCinema/releases/latest)** На странице релиза выберите установщик `PCinema-Setup-*.exe` в разделе Assets. Его можно установить поверх предыдущей версии без сброса библиотеки и истории.

Исходники и инструкция самостоятельной сборки доступны ниже. Установщик включает .NET Runtime и LibVLC: пользователю не требуется отдельно устанавливать .NET или VLC. Установка выполняется для текущего пользователя, без прав администратора.

1. Откройте **Настройки → Источники библиотеки** и добавьте папку с сериалами.
2. Для постеров и описаний выберите **Свой токен** и укажите [TMDB API Read Access Token](https://developer.themoviedb.org/docs/getting-started). Без токена локальная библиотека и просмотр работают.
3. Откройте сериал и нажмите **Смотреть** или **Продолжить**.
4. Справа у серии находятся запуск, отметка просмотра и меню **⋯**: начать заново, указать другой файл, исправить номер.
5. В меню **⋯** рядом с основной кнопкой сериала можно сменить сопоставление TMDB, выбрать постер и прочитать полное описание.

Поддерживаемые файлы: **MKV, MP4, AVI, MOV, M4V, TS**. Примеры распознаваемых имён:

```text
Show.S01E02.mkv
Show.1x02.mp4
Название/Сезон 1/Серия 2.mkv
```

Неоднозначные номера требуют ручного исправления. Файлы с несколькими сериями автоматически не разделяются.

## Управление плеером

| Действие | Управление |
| --- | --- |
| Пауза / воспроизведение | Пробел или щелчок по видео |
| Перемотка на 10 секунд | Стрелки влево / вправо |
| Полный экран | F или двойной щелчок по видео |
| Громкость | Колесо мыши над видео или ползунок |
| Назад | Esc: закрыть меню → выйти из полного экрана → вернуться |
| Дорожки и оформление субтитров | Кнопка настроек в плеере |

Обычное разворачивание окна сохраняет место для панели задач Windows. Полный экран — отдельный режим.

## Данные и приватность

База SQLite, настройки и кэш изображений находятся в `%LocalAppData%\PCinema`. Пользовательский токен защищается Windows DPAPI. Интернет используется для метаданных и изображений; приложение не загружает видео на сервер.

Удаление источника из библиотеки не удаляет видео или историю. Перемещённую серию можно перепривязать через **⋯ → Указать другой файл…**. Данные приложения остаются после деинсталляции.

**Секреты, пользовательские базы, тестовые видео и готовые сборки исключены из Git.** Публичные исходники собираются без встроенного токена TMDB. Не добавляйте свой токен в исходники или коммиты.

## Сборка из исходников

Понадобятся Windows, **.NET 10 SDK** и, для установщика, **Inno Setup 6.7+**.

```powershell
git clone https://github.com/Anat0o/PCinema.git
cd PCinema
dotnet test PCinema.Tests/PCinema.Tests.csproj -c Release
dotnet run --project PCinema/PCinema.csproj -c Release
```

Создание автономного приложения и установщика:

```powershell
./build.ps1 -Dotnet dotnet -Iscc 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe'
```

Сценарий запускает тесты, публикует приложение в `artifacts/publish` и создаёт `artifacts/PCinema-Setup-1.2.0.exe`.

Для издательских сборок поддерживается необязательный ресурс `.secrets/tmdb.token`, исключённый из Git. Токен в бинарном ресурсе можно извлечь: для публичной сборки предпочтительнее ввод собственного токена в настройках.

## Проверка

В проекте 37 автоматических тестов: разбор имён, сканирование, история серий, миграции, источники, метаданные, субтитры и автоплей.

Дополнительная проверка настоящего декодера (нужны собственные MP4 и MKV; MKV — с двумя аудиодорожками и субтитрами):

```powershell
dotnet run --project PCinema.Smoke -c Release -- 'path\episode.mp4' 'path\episode.mkv'
```

Для изолированных проверок задайте переменную `PCINEMA_DATA_DIR`. Результаты ручных проверок и непроверенные сценарии описаны в [VERIFICATION.md](VERIFICATION.md). Ускорение первого открытия обеспечивается фоновой подготовкой плеера; время после перезагрузки Windows отдельно не измерялось.

## Устройство проекта

| Компонент | Назначение |
| --- | --- |
| `PCinema` | WPF-приложение на C# / .NET 10 |
| `LibraryScanner`, `NameParser` | Сканирование папок и разбор имён |
| `LibraryStore`, `LibraryHistory`, `ProgressService` | SQLite и история просмотра |
| `TmdbService` | Метаданные и кэш изображений |
| `PlaybackEngine`, `PlayerWindow` | LibVLC и интерфейс плеера |
| `PCinema.Tests` | Автоматические тесты |
| `PCinema.Smoke` | Проверка воспроизведения на реальных видео |
| `installer` | Установщик Inno Setup |

Первая версия рассчитана на одного пользователя и сериалы. Фильмы, семейные профили, облачная синхронизация, скачивание видео и сетевой стриминг не входят в её задачи. Для разных монтажных версий одной серии сохранённое время может не совпадать.
